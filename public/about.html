The short version

ProjectForge is an independently built project management platform — the kind of tool a solo developer wishes existed the first time a group project spiraled into forty WhatsApp messages and a lost Google Doc. It combines the parts of Trello, ClickUp, Asana, and Notion that actually get used, and leaves out the rest.

It's built on a straightforward stack — HTML, CSS, and JavaScript on the frontend, Node.js and Express on the backend, Firebase for auth, data, and storage — so it stays fast, affordable to run, and easy to extend.
